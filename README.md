# Risy Sales · Landing page

Site estático (HTML + CSS, sem build) da Risy Sales Estética, João Pessoa/PB.

- `index.html`: a página
- `img/`: fotos

## Publicar no Vercel
Importe este repositório em vercel.com/new. Framework: **Other**. Sem comando de build, diretório de saída `./`.

A página está com `noindex` enquanto é protótipo. Remova a linha `<meta name="robots" content="noindex">` quando for ao ar de verdade.
